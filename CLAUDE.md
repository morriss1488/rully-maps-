# CLAUDE.md — рабочая документация проекта

## Что это
«Ралли Алматы»: одностраничное веб-приложение (один файл `index.html`, без сборки). Спутниковая карта (Leaflet), GPS-скорость, маршруты (OSRM), голосовой штурман на Web Speech API. Интерфейс и голос — на русском.

## Стек и правила
- Только vanilla JS + Leaflet 1.9.4 с cdnjs. Никаких сборщиков и npm.
- Внешние сервисы (без ключей): Esri World Imagery и Reference (тайлы), OSM (схема), OSRM `router.project-osrm.org` (маршруты), Nominatim (поиск), Open-Meteo Elevation (высоты).
- Всё в одном файле: CSS в `<style>`, JS в конце `<body>`. Светлая и тёмная тема через CSS-переменные.
- Хранилище: `localStorage` (`rr_routes` — сохранённые маршруты, `rr_set` — настройки). Всегда в try/catch.
- GPS работает только по https (GitHub Pages / Netlify). Опубликованные страницы claude.ai блокируют внешние тайлы и запросы, поэтому этот файл нельзя публиковать там как артефакт.

## Структура `index.html` (по порядку)
1. Карта и слои (спутник/схема), список мест `PLACES`.
2. Состояние, `hv()` расстояние, `brg()` азимут.
3. Голос: `say()`, `phrase()` (фразы навигатора), `arrow()`.
4. `onPos()` — приём GPS: скорость, путь, маркер, слежение. `watchPosition`.
5. Цель и маршрут: `setTarget()`, `routePts()`, `build()` (OSRM, шаги, контрольные точки `route.vias`, пересборка).
6. Ралли-диктовка: `buildNotes()` (кривизна → шкала 1–6), `extraNotes()` («узко», контрольные точки, ваши пометки), `loadElev()` (трамплины, уклон), `pack()` (фраза с дистанциями), `rally()`.
7. `navUpdate()` — режимы «Нави»/«Ралли», уход с маршрута.
8. Демо (`sim`), редактор маршрута (`addWp`, `addNote`, сохранение, GPX), настройки (`GT`, `OFF`).

## Язык штурмана
- Флаг `EN` (хранится в `localStorage.rr_lang`), переключается в ⚙. Голос: `VO.ru` / `VO.en` (en-GB, предпочтительно мужской), `say()` и `sy(ru,en)`.
- Все произносимые строки должны идти через `sy()` или быть языко-зависимыми (`tx`, `phrase`, `rnd`, `finishSay`), иначе английский голос прочтёт русский текст.
- Английские пассноты: `txEN()`; словарь: `TXEN`, `MODEN`; связки в `pack()`. Угол поворота хранится в `note.ang`.
- Слова и логика описаны в `PACENOTES.md`. Оригинальный голос и записи WRC 10 не используются: это синтез речи браузера.

## Знаки пасснот
- `icon(n,size)` рисует SVG-знак по гайду (цвета `COL`, углы дуг `ICN`, `cls(n)` → 1–6 / `sq` / `hair`), `STRAIGHT` — синий знак «прямо», `stripHTML()` — лента ближайших записей с числами-дистанциями.
- Метки препятствий: `MKI` (emoji) и `TXEN` (английские названия); добавляя новую метку, обновить `<select id="tool">`, `MKI`, `TXEN`, `PACENOTES.md`.
- Формат записи — «номер, сторона» (`3 Right · Long`).

## Ключевые решения
- Пассноты считаются из геометрии маршрута: шаг 10 м, поворот на окне 20 м, радиус → номер (R<15 → 1, <30 → 2, <55 → 3, <90 → 4, <150 → 5, <250 → 6; шестёрка только при угле ≥30°).
- Безопасная скорость по номеру: `SAFE_V = [0,7,11,15,21,28,36]` м/с.
- Вызов пасснот: `lead = max(60, 150+OFF*15, speed*(8+OFF))`.
- Уклон «плюс/минус» берётся из высот с шагом ≥100 м (DEM ~90 м), порог `GT` процентов.
- Контрольные точки: промежуточные шаги OSRM получают тип `via` (чтобы не считались финишем).
- Для перестроения на своём маршруте считаем пройденные точки по `route.vias` и `route.skip`.

## Как проверять изменения
- Синтаксис: вынуть `<script>` из файла и `node --check`.
- Логику пасснот можно проверять на синтетическом маршруте в node (stub-функции `hv`, `brg`, `posAtD`); GPS и карту — только на устройстве.
- После правки: залить `index.html` в репозиторий, подождать 1–2 минуты Pages.

## Статус проверки
- По скриншотам пользователя (iPhone, Netlify): карта-спутник, маршрут, пассноты и подпись «4 лево · 2 право узко» отображаются.
- Не подтверждено в движении: реальная скорость от GPS, голос штурмана, перестроение при съезде, свой маршрут и сохранение на устройстве.
- Android-магнитола: в меню Chrome нет «Добавить на главный экран»; варианты — главная страница в настройках, закладка, значок установки в адресной строке.

## Известные ограничения / идеи
- OSRM демо-сервер без гарантий и без пробок; Nominatim и OSM-тайлы — только лёгкое использование (проверьте условия сервисов перед широкой публикацией).
- «Не режь» и «узко» — эвристики; настоящих данных о ширине и препятствиях нет.
- Идеи: импорт GPX, список пасснот с правкой, предупреждения о превышении, запись трека, платный/собственный роутер.
