# Ралли Алматы — GPS-штурман

Веб-приложение для телефона и автомагнитолы: спутниковая карта Алматы и области, GPS-скорость, маршруты по дорогам и голосовой штурман, который диктует повороты как в настоящем ралли («четыре право затяжной, 80, трамплин»).

**Сайт:** https://morriss1488.github.io/rully-maps-/

## Возможности

- Спутниковый снимок (Esri) и схема (OpenStreetMap), свободное перемещение и масштабирование, кнопка слежения за машиной.
- GPS: скорость, максимальная скорость, пройденный путь, направление, точность.
- Цель: список мест Алматы и области, поиск по названию, касание карты.
- **Свой маршрут** (✏️): точки на карте, перетаскивание, свои пометки («не режь», «узко», «трамплин», «осторожно»), сохранение в браузере, экспорт в GPX.
- **Ралли-диктовка:** шкала 1–6 (1 — шпилька, 6 — почти прямо), «затяжной», «закрывается/открывается», «трамплин/перегиб» по профилю высот, «плюс/минус» для подъёмов и спусков, «не режь», «узко», дистанции между записями.
- **Знаки пасснот как в гайде 1–6** (square, hairpin, long, препятствия) и лента ближайших записей с дистанциями.
- **Английский штурман в стиле WRC** (⚙ → «Язык штурмана»), словарь слов — в `PACENOTES.md`.
- Режим «Нави» с обычными подсказками («через 500 метров направо на …»), перестроение при съезде с маршрута.
- Режим «Демо» — едет по маршруту без GPS. Настройки (⚙): порог «плюс/минус», смещение вызова пасснот.

## Запуск

Это один статический файл `index.html`, сборка не нужна. Нужен **https** (иначе браузер не отдаёт GPS) и интернет.

1. Загрузите `index.html` в репозиторий (в корень).
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, `/ (root)` → Save.
3. Откройте `https://<логин>.github.io/<репозиторий>/`, разрешите геолокацию и звук.
4. На телефоне: «Поделиться → На экран Домой».

Локально: `python3 -m http.server` и `http://localhost:8000`.

## Ограничения

- Карта, маршруты, поиск и высоты берутся из внешних сервисов (Esri, OSM, OSRM, Nominatim, Open-Meteo), без интернета не работают.
- Маршруты строит демо-сервер OSRM без гарантий и без пробок.
- Высоты — модель рельефа ~90 м: мелкие трамплины не видны.
- «Не режь» и «узко» подсказываются эвристикой, настоящей ширины дороги и препятствий у приложения нет.
- Это не замена рекогносцировки и не навигатор для безопасного вождения: соблюдайте ПДД.
